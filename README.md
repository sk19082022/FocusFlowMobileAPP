## 🌟 About Focus Flow

Focus Flow is a productivity-focused mobile application that combines:

- 🎯 Focus Sessions
- ⏳ Pomodoro Timer
- 📊 Productivity Analytics
- 📅 Calendar Tracking
- ✅ Todo Management
- 🏆 Achievements System
- 🔔 Smart Notifications

into one clean and distraction-free experience.

Whether you're:

- 📚 A Student
- 💻 A Developer
- 🎨 A Creator
- 🏋️ A Fitness Enthusiast

Focus Flow helps you stay accountable and productive every day.

---

# ✨ Features

## 🎯 Focus Tasks

Create productivity-oriented tasks such as:

- Read 30 Minutes
- Learn Flutter
- Practice DSA
- Workout
- Learn UI Design

Each task contains:

✅ Task Name

✅ Focus Duration

✅ Progress Tracking

✅ Calendar History

✅ Completion Statistics

---

## ⏳ Focus Timer

Every task comes with a built-in Pomodoro-style timer.

### Controls

▶️ Start

⏸ Pause

🔄 Resume

🏁 Complete Session

When a session finishes:

- Task progress updates automatically
- Completion date is saved
- Calendar gets updated
- Notification can be cleared
- Completion sound plays

---

## 📅 Calendar Consistency Tracker

Track your productivity visually.

### Calendar Indicators

| Status | Meaning |
|----------|----------|
| 🟢 | Completed |
| 🔴 | Missed |
| ⭐ | Today |
| ⚪ | Pending |

This provides a powerful visual representation of consistency over time.

---

## 📊 Analytics Dashboard

Track your performance with detailed analytics.

### Metrics

📈 Completion Percentage

📆 Total Focus Days

🔥 Productivity Streaks

📊 Task Progress

🎯 Goal Completion Rate

### Formula

```text
Progress % =
Completed Days
------------------ × 100
Days Since Creation
```

---

## ✅ Todo Management

Separate from focus tasks.

### One-Time Todos

Examples:

- Finish Assignment
- Submit Project
- Attend Interview

Status Types:

🟡 Pending

🟢 Completed

🔴 Overdue

---

### Daily Todos

Examples:

- Exercise
- Drink Water
- Meditation
- Journal Writing

Track consistency daily through calendar indicators.

---

## 🏆 Achievements System

Completed goals move into a dedicated achievements section.

Example:

```text
Flutter Course
Completed Successfully
```

Achievements show:

🏅 Task Name

📅 Completion Date

⏱ Total Focus Time

📊 Completion Statistics

This creates a permanent history of accomplishments.

---

## 🔔 Smart Notifications

Receive notifications while focusing.

Example:

```text
Focus Flow

Learning Flutter

24:30 Remaining
```

### Features

- Background Execution
- Ongoing Notification
- Auto Updates
- Session Completion Alert

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/sk19082022/FocusFlowMobileAPP.git
```

## Open Project

```bash
cd FocusFlowMobileAPP
```

## Install Packages

```bash
flutter pub get
```

## Run App

```bash
flutter run
```

---

## Build Release APK

```bash
flutter build apk --release
```
